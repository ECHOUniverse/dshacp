速查卡：在 Zed 中验证 DSHACP

打印友好版。每个验证点给"怎么测 + 看到什么算过"。

一、安装与配置

# 1. 构建 + 全局链接（在项目目录）
cd /Volumes/WD-1T/00_Workspace/00_Active/CodeProject/DSHACP
npm run build
npm link
which dshacp       # 应输出路径；dshacp --help 显示用法说明

# 2. 服务端自测（不依赖 Zed）
printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":1,"clientCapabilities":{},"clientInfo":{"name":"t","version":"0"}}}' | dshacp
# 期望输出：一行 JSON，含 "loadSession":true 和 "authMethods":[]

Zed 配置（~/.config/zed/settings.json → agent_servers 里加）：

"DSH": {
  "type": "custom",
  "command": "dshacp",
  "args": [],
  "env": {}
}

保存后 完全退出 Zed 再重开（⌘Q）。

二、功能验证清单

验证点怎么测看到什么算过
流式输出任意提问文字逐个冒出来（不是一次性出现）
思考过程问一个需要推理的问题先出现思考内容，再出现正式回复
工具卡片"运行 pwd"bash 卡片出现 → 完成 → 卡片显示输出
文件写入"创建 zed-test.txt，内容 xxx"文件树出现该文件，内容正确
审批弹窗"运行 touch ~/test-file"（写家目录）出现权限请求：允许一次 / 始终允许 / 拒绝
会话列表/恢复关闭线程 → 新线程选择历史会话Threads 侧栏列出会话，点开能看到历史并继续对话
ssh 工具"调用 ssh_list"出现 ssh_list 工具卡片（无主机配置时返回 no hosts configured 也算工具通了）

四、快速排错表

症状原因 → 处理
选不到 DSH agent配置没保存或没重启 → ⌘S 保存 + ⌘Q 重启
Failed to start agentdshacp 不在 PATH → which dshacp，重新 npm link
转圈后报错密钥问题 → 检查 ~/.dsh/.credentials.yaml 的 DEEPSEEK_API_KEY
有回复但没有思考正常——模型/配置决定是否输出思考，不是故障
审批弹窗不出现命令在沙箱允许范围内（工作区/临时目录内操作不询问）→ 换写家目录的命令测
权限请求一直转圈审批默认 10 分钟超时，超时后自动拒绝（fail-closed）→ 等它超时或取消
